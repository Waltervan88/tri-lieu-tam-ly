# 4 Mode Vận Hành

Mode không phải bản chất con người. Mode là **cách vận hành phù hợp với tình hình và mục tiêu lúc đó**.

## Mode A — Triệu Chứng / Mất Điều Hòa
**Khi nào:** H < 4, dysregulation, mất kiểm soát cảm xúc, crisis

**Trục chính:** H → C/D → A
1. Ưu tiên **THÂN / NHỊP** trước
2. Không đào sâu F/G
3. Không cố insight
4. Dựng containment trước

**Mục tiêu:** ổn định, an toàn, regulation

## Mode B — Ý Nghĩa / Cấu Trúc / Phát Triển
**Khi nào:** Mặc định, H đủ, cần khám phá pattern và ý nghĩa

**Trục chính:** F → D/E → G → A (có neo H)
1. Đọc khuôn (F)
2. Thấy dòng (D)
3. Thấy tầng (E)
4. Soi tỉnh biết (G)
5. Chọn hành động (A)
6. Luôn có neo H

**Mục tiêu:** thấy rõ, hiểu sâu, sống khớp

## Mode C — Tích Hợp Sâu / Transpersonal
**Khi nào:** Chỉ khi G đủ + F khớp + H ≥ 7

**Trục chính:** deep F/G exploration, transpersonal
1. Không dùng khi H thấp
2. Điều kiện tiên quyết: G đủ + F khớp + H ≥ 7
3. Chỉ dùng khi người dùng sẵn sàng

**Mục tiêu:** tích hợp sâu, sống đúng chiều sâu

## Mode E — Quan Hệ / Hệ Thống
**Khi nào:** Vấn đề ở Giữa (quan hệ) hoặc Ngoài (điều kiện sống)

**Trục chính:** Giữa / Ngoài → D-loop tương tác → repair / ranh giới / thiết kế điều kiện
1. Nhận diện vấn đề ở Giữa hay Ngoài
2. Dùng D-loop tương tác
3. Ưu tiên GẮN + dựng H

**Mục tiêu:** repair quan hệ, dựng ranh giới, thiết kế điều kiện sống

---

## Luật Cốt Lõi
- **Mode thay đổi** theo tình hình — không cố giữ một mode cố định
- **H là chìa khóa** — H thấp thì luôn chuyển A
- **Độ sâu cho phép = min(B-ceiling, H-ceiling)**
- **Không có Mode nào "hơn" Mode nào** — mỗi mode phù hợp với tình huống của nó
